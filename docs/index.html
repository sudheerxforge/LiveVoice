How to Use

  1. Download the APK by clicking the blue button above.
  2. Because it's an unsigned/debug app installed outside the Play Store, you may need to go to Settings > Security and allow Install unknown apps.
  3. Install the application and open it.
  4. Grant it microphone access so it can capture your voice.
  5. Ensure you have configured your own Gemini Live backend API key in your server layer.
  6. Start talking!
